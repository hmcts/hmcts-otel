# Telemetry conventions

Generated by `scripts/generate_conventions.py` from `hmcts_otel/schema.py`. Do not edit by hand.

These are the core attributes every service gets. Services register their own
attributes and events in their schema and should publish the same table, using
`default_schema.to_markdown()`.

## Naming

- Attribute, event and stage names: lower-case dotted snake case, e.g. `speech.cancel_reason`.
- Events from a stage: `<stage>.started`, `<stage>.completed`, `<stage>.failed`, `<stage>.cancelled`.
- Error codes: controlled values such as `speech.timeout`, never messages.
- Identifiers: system-generated (UUIDs). Never case references, file names, names or emails.

## Metrics

| Metric | Type | Unit | Dimensions |
|---|---|---|---|
| `hmcts.stage.duration` | histogram | s | `hmcts.stage`, `hmcts.outcome`, `hmcts.error.code`, `hmcts.journey.type` |
| `hmcts.events` | counter | event | `event`, `class`, `source` |
| `hmcts.event.duration` | histogram | s | `event`, `class`, `source` |
| `hmcts.telemetry.dropped_attributes` | counter | attribute | `reason`, `where` |
| `hmcts.telemetry.errors` | counter | error | `kind` (`invalid.*` misuse, `internal.*` failures) |

Duration histograms use bucket boundaries (seconds): `0.005, 0.01, 0.025, 0.05, 0.1, 0.25, 0.5, 1, 2.5, 5, 10, 30, 60, 120, 300, 600, 1800, 3600`.
In App Insights only count, sum, min and max are kept; compute percentiles from events.

Journey IDs are never metric dimensions.

## Core attributes

| Attribute | Type | Rule | Description |
|---|---|---|---|
| `hmcts.dependency.ref` | str | matches `[A-Za-z0-9_.:-]{1,128}` | Reference in an external system, e.g. Azure Speech job ID. |
| `hmcts.duration_ms` | float | — | Duration in milliseconds. |
| `hmcts.error.code` | str | matches `[A-Za-z0-9_.:-]{1,64}` | Controlled error code. Never a message. |
| `hmcts.event.class` | str | one of `analytics`, `operational` | operational or analytics. |
| `hmcts.event.source` | str | one of `browser`, `server` | server or browser. |
| `hmcts.journey.id` | str | matches `[A-Za-z0-9_-]{1,64}` | Pseudonymous journey identifier (UUID). |
| `hmcts.journey.parent_id` | str | matches `[A-Za-z0-9_-]{1,64}` | Parent journey, e.g. the batch a file belongs to. |
| `hmcts.journey.type` | str | matches `[a-z0-9][a-z0-9_.-]{0,63}` | Kind of journey, e.g. upload.job or user.session. |
| `hmcts.outcome` | str | one of `cancelled`, `error`, `failure`, `success` | Stage outcome. |
| `hmcts.request.id` | str | matches `[A-Za-z0-9._-]{1,64}` | Request correlation ID. |
| `hmcts.stage` | str | matches `[a-z][a-z0-9_.]{0,63}` | Stage name. |
